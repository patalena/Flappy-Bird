Flappy Bird | Курсовая работа.
Классическая аркада Flappy Bird, реализованная на C++ с использованием библиотеки SFML. Проект выполнен в рамках курсовой работы по дисциплине «Программирование на языках высокого уровня».

Особенности.
3 уровня сложности (Easy, Normal, Hard) с независимой настройкой гравитации, силы прыжка, скорости труб и ширины просвета, 3 скина птицы с сохранением выбора между запусками, сохранение прогресса: рекорды и настройки хранятся в локальных .txt файлах, уменьшенный хитбокс столкновений для более точного геймплея, движение и физика не зависят от FPS (delta time), модульная архитектура: разделение логики на классы Bird, Pipe и основной игровой цикл.

Управление.
Пробел: Прыжок / Старт игры / Перезапуск после Game Over.
Стрелки ВЛЕВО/ВПРАВО (в меню): Смена скина птицы.
Стрелки ВВЕРХ/ВНИЗ (в меню): Выбор уровня сложности.
